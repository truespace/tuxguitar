TuxGuitar links

A tuxguitar: link opens a song from a web page, and on macOS brings its recording along. Open this file in a browser to build one, or copy the examples into a page of your own.

Parameters

pathThe file to open. Relative to the Documents folder of the app on iPadOS (what the Files app shows as On My iPad / TuxGuitar) and to the home folder on macOS; an absolute path works as well.
musicmacOS only. Switches Apple Music sync on and silences the score, since the recording is what the link is for. Give it the name of a track to load it from the library; written on its own, it plays along with whatever Music already has loaded.

A value containing spaces or non-latin characters has to be percent encoded (a space becomes %20). The builder below does that for you.

Opening a score — iPadOS and macOS

A file in the folder of the apptuxguitar://open?path=song.gp5 The same, written shorttuxguitar://song.gp5 A subfolder, and a space in the nametuxguitar://open?path=songs/My%20Song.gp5 An absolute pathtuxguitar:///Users/me/songs/song.gp5

Opening a score with its recording — macOS only

Load a track of the library by nametuxguitar://open?path=song.gp5&music=My%20Song Play along with the track Music has loadedtuxguitar://open?path=song.gp5&music

The name is matched against the library, exactly first and as a part of a title otherwise, so music=Pretender finds "Pretender" rather than "The Pretender". Press play in TuxGuitar and the recording starts with it; the dialog under Tools › Apple Music sync holds the offset, the speed and the drift between them.
